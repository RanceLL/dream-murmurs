# 梦呓

和朋友在线玩的说梦卡牌游戏。

打开 https://rancell.github.io/dream-murmurs/ ，点「开一个房间」，再把房间链接发给朋友。朋友打开链接就能入座，不用注册，也不用登录。

- 3 到 8 人，人不够可以加电脑玩家
- 每轮一位讲述者从手牌挑一张梦境卡，说一句线索；其他人各出一张最像的牌混进去，再一起猜哪张是讲述者的
- 有人猜中也有人没猜中，讲述者和猜中的人各得 3 分；所有人都猜中或没人猜中，讲述者 0 分、其他人各得 2 分；你的牌每骗到一票再得 1 分
- 房间里可以开实时语音（点右上角「语音」，最好戴耳机）
- 线索会用讲述者选的声线朗读出来，另有音效和可开关的背景音乐
- 600 张卡面都是程序即时画出的原创梦境图
- 也可以点「本机多人」，在一台设备上轮流玩

玩法受经典说故事类桌游启发，卡面、名称和画面都是原创内容。

联机消息和语音的连线信号通过公共 MQTT 服务器转发（broker.emqx.io，备用 broker.hivemq.com），语音本身是浏览器之间直接连线。拿到房间链接的人都能进入房间。部分手机网络之间可能无法直接连线，这时语音会显示「语音连不上」，游戏本身不受影响。

第三方代码：MQTT.js 5.14.1，MIT 许可，见 LICENSE-mqtt.md。
