# 梦呓

和朋友在线玩的说梦卡牌游戏。

打开 https://rancell.github.io/dream-murmurs/ ，点「开一个房间」，再把房间链接发给朋友。朋友打开链接就能入座，不用注册，也不用登录。

- 3 到 8 人，人不够可以加电脑玩家
- 每轮一位讲述者从手牌挑一张梦境卡，说一句线索；其他人各出一张最像的牌混进去，再一起猜哪张是讲述者的
- 有人猜中也有人没猜中，讲述者和猜中的人各得 3 分；所有人都猜中或没人猜中，讲述者 0 分、其他人各得 2 分；你的牌每骗到一票再得 1 分
- 房间里可以开实时语音（点右上角「语音」，最好戴耳机）
- 线索会用讲述者选的声线朗读出来，另有音效和可开关的背景音乐
- 也可以点「本机多人」，在一台设备上轮流玩

玩法受经典说故事类桌游启发。

## 牌面图片怎么加

**往 `pictures/` 文件夹上传图片就行，别的都是自动的。**

1. 打开 https://github.com/RanceLL/dream-murmurs/tree/main/pictures
2. 点 **Add file → Upload files**，把图片拖进去（一次最多 100 张，可以分几次传）
3. 点 **Commit changes**

上传后 GitHub Actions 会自动运行「整理牌面」（仓库的 Actions 页面能看到进度和报告，一般一两分钟），然后网站上的牌就更新了。

图片的格式、大小、比例、文件名都不用管：

- 每张图裁成 2:3 竖版；比例差太多的（横图、方图）整张放进去，用同一张图的模糊放大版垫底
- 生成两种 WebP：手牌和桌面用的小图（320×480，平均约 20 KB），点开看的大图（最宽 800，平均约 80 KB）。原图平均约 230 KB，最大的有 7 MB
- 看起来一样的图只留最清楚的一张，重复的会列在报告里
- 分辨率偏低（点开看会糊）的图也会列在报告里，可以换成更清楚的版本
- 想去掉某张牌，删掉 `pictures/` 里对应的原图即可（`cards/manifest.json` 里每张牌都记着原图路径）

## 为什么现在加载快

- 游戏只下载用得到的尺寸：手牌、桌面用小图，点开才拿大图
- 所有牌的超小缩略图拼在一张图里（约 50 KB），一打开就能先显示模糊的预览，不会出现空白牌
- 拿到手牌后先把这几张的大图准备好；开局几秒后，空闲时在后台把整副牌的小图存到本机（流量节省模式下不做）
- 文件名带内容哈希，看过的牌存在本机（Service Worker 缓存），下次打开直接用，断网也能打开
- 牌堆就是 `pictures/` 里不重复的图，有多少张就是多少张，同一局里不会出现两张一样的牌

## 文件说明

| 路径 | 内容 |
|---|---|
| `pictures/` | 上传的原图，随便放 |
| `cards/` | 自动生成，不要手动改：`s/` 小图、`l/` 大图、`mini-*.webp` 缩略拼图、`manifest.json` 牌的顺序 |
| `tools/build_cards.py` | 整理牌面的脚本，本机也能跑：`pip install pillow && python3 tools/build_cards.py` |
| `.github/workflows/cards.yml` | 上传图片后自动运行上面的脚本，并把网站同步到 `gh-pages` 分支 |
| `index.html`、`sw.js`、`mqtt.min.js` | 游戏本身、离线缓存、联机用的库 |

联机消息和语音的连线信号通过公共 MQTT 服务器转发（broker.emqx.io，备用 broker.hivemq.com），语音本身是浏览器之间直接连线。拿到房间链接的人都能进入房间。部分手机网络之间可能无法直接连线，这时语音会显示「语音连不上」，游戏本身不受影响。
